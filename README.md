# Domo Arigato portfolio

Static GitHub Pages version of the approved v15 browser test. Publish the repository root from the main branch.

Three.js license: `vendor/three/LICENSE`.

On screens up to 700px, the workshop uses portrait stills rendered from
`DA_Workshop_v21_WallCleanup.blend` rather than loading the large workshop GLB.
The soundstage keeps its 3D scene with a wider mobile camera and falls back to
still imagery if WebGL is unavailable. Desktop uses the original camera paths.
